# 傅立叶函数可视化编辑器

用图形界面而不是公式来编辑傅立叶级数: 增删和调整一组旋转向量(谐波分量), 让它们随时间转动,
在"波形"和"二维绘图"两种模式下看到合成出的图形; 用关键帧让参数随时间变化; 把作品保存在浏览器里,
或导出为 PNG / MP4.

纯前端应用, 无需安装、注册或服务器. 数据只保存在当前浏览器中.

## 运行

需要 Node.js ≥ 22 与 pnpm ≥ 9.

```bash
pnpm install
pnpm dev              # 开发服务器
pnpm test             # 单元 / 组件 / 集成测试
pnpm test:coverage    # 覆盖率门槛: 整体 80%, src/core 95%
pnpm exec playwright install && pnpm test:e2e   # 端到端、可访问性、响应式
pnpm test:perf         # 50 个分量的渲染基准 (桌面 Chromium, 含 4× CPU 降速估算)
pnpm lint && pnpm typecheck
pnpm size             # 生产构建 + 包体预算检查
```

## 画面显示选项

工具栏上的"网格"和"坐标轴"是两个独立开关. "画面"面板里可以:

- 关闭"轨迹淡化", 让划过的轨迹保留下来(可选保留 5 秒到 10 分钟, 或"全部"); 最新一段更亮, 更早的轨迹以稳定的正常亮度显示, 不会消失.
  闭合(周期性)图形只需描一圈就完整; 频率很高的函数会自动缩短实际保留时长以保证形状正确, 面板里会说明.
- 选择画布背景色(四个预置、取色器或输入 `#RRGGBB`), 网格、坐标轴、轨迹和各分量的颜色会自动调整到可辨识的对比度; "恢复默认"回到深色荧光屏.

这些选项随应用记住, 不随单个作品保存.

## 从图形得到函数

分量面板的"图形"按钮打开三种来源:

- **图形库**: 雪花、五角星、心形、圆、正多边形、字母 F. 点选即把该图形的傅立叶函数装进编辑器, 旋转向量在二维绘图模式下把它一笔画出; 分量数滑块(2–200)决定逼近的精细程度.
- **手绘**: 在画布上一笔画出闭合形状, 松手后向量沿着它重描一遍; "平滑程度"滑块去抖动, 可随时再调.
- **导入 SVG**: 取文件中最长的一条路径. 只在本地解析, 不执行脚本、不加载外部资源, 文件不上传.

生成的函数与手工搭建的没有区别, 可以继续编辑、保存、导出. 分量上限为 200 个.

## 快捷键

| 按键 | 作用 |
|---|---|
| 空格 | 播放 / 暂停 |
| ← / → | 后退 / 前进一步 (1/60 秒); 焦点在关键帧上时移动该关键帧 (Shift 为 0.001 秒) |
| Home | 重置到 0 秒 |
| Ctrl/Cmd + Z, Shift + Ctrl/Cmd + Z | 撤销 / 重做 |
| Delete | 删除获得焦点的关键帧 |

焦点在输入框、滑块内, 或按键会激活当前按钮时, 全局快捷键不触发.

## 浏览器支持

Chrome / Edge、Firefox、Safari 的当前版本. 视频导出需要浏览器支持 WebCodecs 的 H.264 编码;
不支持时该入口会禁用并说明原因, 其余功能不受影响.

## 已知限制

- 频率高于约 30 圈/秒时, 旋转向量本身会因屏幕刷新率出现"车轮效应"式的视觉混叠;
  轨迹与波形不受影响, 降低播放速度即可观察.
- 图形转换只处理一条闭合路径; 多路径的 SVG 取最长的一条; 不支持 skew 变换、镂空与填充; 不支持位图.
- 极精细的图形在 200 个分量下会被平滑.
- "全部"最多保留最近 10 分钟的轨迹. 背景色只支持不透明纯色, 线条颜色不能逐项自定义.
- 已保存的函数只存在于当前浏览器; 清除站点数据会丢失. 不提供函数文件的导入导出与跨设备同步.
- 撤销历史不跨页面刷新保留. 导出的视频不含声音, 单段成片最长 60 秒.

## 文档

规范、计划、数据模型与任务见 `specs/001-fourier-visual-editor/`; 项目原则见
`.specify/memory/constitution.md`. 其中最重要的一条: **图形只由"当前函数"和"时刻 t"决定**,
禁止逐帧累加角度或轨迹——拖动时间轴、循环、视频导出的一致性都建立在它之上.
