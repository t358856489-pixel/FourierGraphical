# 功能规范: 从图形得到傅立叶函数

**功能分支**: `003-shape-to-fourier`
**创建时间**: 2026-09-24
**状态**: 草稿
**输入**: 用户描述: "我想通过一些图形描述获得数学函数，然后使用函数绘制线条，比如：我想画一个雪花。"

## Clarifications

### Session 2026-09-24

- Q: "图形描述"是否包含用自然语言描述(如输入"雪花")由系统生成图形? → A: 不包含. 图形只通过图形库、手绘、导入 SVG 三种方式给出
- Q: 分量数上限 50 是否够用(维持 / 仅生成的函数放宽 / 全局放宽)? → A: 全局上限提高到 200: 图形库、手绘、导入与手工添加都可用到 200 个分量
- Q: 手绘路径在转换前如何处理(原样 / 平滑并按弧长重采样 / 平滑且可调)? → A: 平滑并按弧长重采样, 平滑程度由用户用滑块调节
- Q: 应用生成的函数时是否调整显示选项(不动 / 保证轨迹可见 / 切换为保留整幅图形)? → A: 切换为保留整幅图形: 自动打开轨迹显示、关闭轨迹淡化、保留时长设为"全部", 其余显示选项不变

## 用户场景与测试 *(必填)*

现在的编辑器是"先有函数、后有图形": 用户调分量参数, 看合成出什么图案. 本功能反过来: 用户先给出一个想要的图形——
比如一朵雪花——系统算出能画出它的傅立叶函数(一组旋转向量), 装进编辑器, 让旋转向量在二维绘图模式下把这个图形一笔画出来.
之后用户仍可像编辑任何函数一样调整、保存、导出它.

图形可以通过三种方式给出, 按优先级排列为三个用户故事. 三者共用同一条"图形 → 函数"的转换, 任何一种单独交付都有价值.

### 用户故事 1 - 从内置图形库一键得到函数 (优先级: P1)

用户打开"图形库", 看到一组带缩略图的内置图形: 雪花、五角星、心形、圆、正多边形、字母等. 点选"雪花", 选择用多少个分量来逼近,
编辑器里的分量就被替换成这朵雪花的傅立叶函数; 播放时旋转向量的末端沿着雪花的轮廓走一圈, 画出一朵雪花.
分量越多, 雪花的尖角越清晰; 分量少时得到一个圆润的近似, 用户能直观看到"用多少个圆能画出一朵雪花".

**优先级原因**: 这是用户举的例子("我想画一个雪花"), 也是最省力的入口: 不需要用户会画画、也不需要准备文件. 图形库本身还能用作后两个故事的示范.

**独立测试**: 选择"雪花"、分量数 150, 切到二维绘图模式播放一整圈, 确认画出的轨迹是一朵尖角清晰的六角雪花; 把分量数改为 10, 确认图形变得圆润但仍大致是雪花的形状.

**验收场景**:

1. **给定** 用户打开图形库, **当** 浏览时, **那么** 至少看到 8 个带缩略图和名称的图形, 其中包含雪花
2. **给定** 用户选择了雪花并保持默认分量数, **当** 应用后, **那么** 编辑器的分量列表被替换为雪花的傅立叶函数, 呈现模式切换为二维绘图, 轨迹显示打开、淡化关闭、保留"全部", 时间回到 0 并开始播放; 画完一圈后整朵雪花留在画面上
3. **给定** 已应用雪花, **当** 播放满一个周期时, **那么** 轨迹闭合, 画出的形状与图形库缩略图一致
4. **给定** 已应用雪花, **当** 用户把分量数从 150 改为 10 时, **那么** 分量列表随之增减, 轨迹变为更圆润的近似, 但仍可辨认
5. **给定** 当前函数有未保存的修改, **当** 用户应用图形库中的图形时, **那么** 系统先征得确认(与预设波形一致)
6. **给定** 已应用图形, **当** 用户修改任一分量、保存、导出时, **那么** 行为与手工搭建的函数完全相同

---

### 用户故事 2 - 手绘一个图形并转成函数 (优先级: P2)

用户进入"绘制"模式, 在画布上用鼠标或手指一笔画出一个闭合的形状(比如一只猫的轮廓). 松手后, 系统把这条路径转换成傅立叶函数,
旋转向量随即沿着用户画的轮廓重新描一遍. 手绘难免抖动, 系统会先把路径轻度平滑再转换, 用户可以用"平滑程度"滑块调节, 从几乎原样到很圆润; 也可以清除重画、调整分量数.

**优先级原因**: 让用户画出图形库里没有的任何东西, 是"通过图形描述获得函数"最直接的形态; 但需要用户动手, 且手绘的质量参差, 放在图形库之后.

**独立测试**: 画一个大致的心形并松手, 确认旋转向量画出的轨迹与所画路径的形状一致(位置、大小、方向都对得上); 清除后画布恢复.

**验收场景**:

1. **给定** 用户进入绘制模式, **当** 按住并拖动时, **那么** 画布上实时显示正在画的线, 播放暂停, 现有图形隐藏
2. **给定** 用户画完一笔并松手, **当** 路径至少包含最短可用长度时, **那么** 路径自动闭合(末点连回起点), 转换为函数并开始播放, 轨迹与所画路径重合
3. **给定** 用户画的一笔太短或只是一个点, **当** 松手时, **那么** 系统提示"再画长一些"并保留绘制模式, 不生成函数
4. **给定** 用户在绘制模式中, **当** 点击"清除"时, **那么** 已画的线消失, 可以重新画
5. **给定** 用户已完成一次转换, **当** 调整"平滑程度"滑块时, **那么** 轨迹即时按新的平滑程度重新转换; 滑块最低档时形状与所画路径几乎完全一致(含抖动), 最高档时抖动消失、转角变圆润, 但整体形状仍可辨认
5a. **给定** 用户已完成一次转换, **当** 再画一笔时, **那么** 新的一笔替换旧的图形(先征得确认, 若上一个函数有未保存修改)
6. **给定** 用户用键盘操作, **当** 无法用指针绘制时, **那么** 仍可通过图形库或导入得到函数(绘制本身不要求键盘等价)

---

### 用户故事 3 - 导入矢量图形文件 (优先级: P3)

用户手头有一个 SVG 文件(比如从设计软件导出的 logo 轮廓), 把它拖进应用或通过文件选择器打开, 系统取出其中的路径, 转换为傅立叶函数并画出来.

**优先级原因**: 让精确的、非手绘的图形进入编辑器, 但依赖用户会准备文件, 受众最窄.

**独立测试**: 导入一个只含一条闭合路径的 SVG, 确认画出的轨迹与文件中的图形一致; 导入一个不含路径的 SVG, 确认得到清晰的提示.

**验收场景**:

1. **给定** 用户选择了一个含闭合路径的 SVG 文件, **当** 导入时, **那么** 转换为函数并播放, 轨迹与文件中的图形一致(按画布自动缩放居中)
2. **给定** SVG 含多条路径, **当** 导入时, **那么** 系统取最长的一条并告知用户"已使用其中最长的一条路径"
3. **给定** 文件不是 SVG、无法解析、或不含任何路径, **当** 导入时, **那么** 系统说明原因, 当前函数不变
4. **给定** 文件很大(路径点数极多), **当** 导入时, **那么** 系统在合理时间内完成转换, 界面不冻结

---

### 边界情况

- 用户要求的分量数少于能表达图形的最低数量(如 2 个分量画雪花)时: 仍然生成, 得到一个圆或椭圆的近似, 不报错.
- 分量数达到上限(200)仍不足以清晰表达极精细的图形时: 界面说明"当前上限为 200 个分量, 细节可能被平滑", 生成上限内最好的近似.
- 已保存的函数含 200 个分量时: 保存、打开、导出与撤销全部照常; 分量列表在分量很多时仍可流畅滚动与编辑.
- 手绘路径自相交、或起点与终点相距很远时: 照常闭合并转换, 不做纠正(平滑只去抖动, 不改变拓扑).
- 用户画得时快时慢、点疏密不均时: 转换结果不受影响(转换前按弧长重新均匀取样).
- 手绘时指针移出画布再回来: 继续同一笔; 在画布外松手视为完成.
- 图形的尺寸与画布不匹配(极大或极小)时: 生成的函数在应用时自动归一到与示例函数相当的尺寸, 画布自动适配.
- 生成的分量频率均为基频的整数倍, 因此图形一定闭合、周期确定; 应用后循环区间不变, 显示选项按 FR-007a 调整.
- 用户开启了"减少动态效果"时: 应用图形后不自动播放, 但时间跳到一个周期的末尾, 使整幅图形直接显示出来.
- 图形库、手绘与导入得到的函数与手工搭建的函数在数据上没有区别: 保存、打开、撤销、关键帧全部可用; 撤销一步即可回到应用前的函数.
- 转换过程中用户切换页面或再次点击: 以最后一次操作为准, 不出现两套结果.

## 需求 *(必填)*

### 功能需求

**图形到函数的转换(三个故事共用)**

- **FR-001**: 系统必须能把任意闭合的平面路径转换为一组谐波分量(振幅、频率、相位), 使旋转向量末端在一个周期内沿该路径走一圈
- **FR-002**: 用户必须能够指定用于逼近的分量数(2 到 200), 默认 60; 分量按对图形贡献从大到小排列
- **FR-002a**: 编辑器的分量数上限从 50 提高到 200, 对手工添加、预设波形、图形生成一律适用; 关键帧、撤销、保存、导出在 200 个分量下必须全部可用
- **FR-003**: 转换后画出的轨迹与原路径的偏差必须足够小: 在分量数为 200 且路径不含比周长 1/200 更细的细节时, 轨迹上任一点到原路径的距离不超过图形尺寸的 1%; 分量数为 60 时不超过 3%
- **FR-004**: 生成的分量频率必须是同一基频的整数倍(含负频率), 基频与预设波形一致(0.2 圈/秒), 一个周期为 5 秒
- **FR-005**: 生成的函数在应用时必须自动缩放并居中, 使图形尺寸与内置示例函数相当, 且画布自动适配
- **FR-006**: 应用生成的函数是一次可撤销的编辑, 会替换当前的全部分量(含关键帧); 当前函数有未保存修改时必须先确认
- **FR-007**: 应用生成的函数时, 系统必须把呈现模式切换为二维绘图、时间归零并开始播放, 让用户立即看到图形被画出来
- **FR-007a**: 同时系统必须把显示选项调整为"保留整幅图形": 打开"轨迹"显示、关闭"轨迹淡化"、保留时长设为"全部"; 网格、坐标轴、向量、圆、背景色等其余显示选项不变. 这些改动与用户手动修改显示选项等价, 之后可随时改回
- **FR-008**: 生成的函数与手工搭建的函数在后续编辑、保存、导出上必须没有任何区别

**图形库**

- **FR-009**: 系统必须提供至少 8 个内置图形, 含: 雪花(六角)、五角星、心形、圆、正三角形、正方形、正六边形、字母 F(有方向、不对称, 便于看出描绘方向)
- **FR-010**: 每个内置图形必须有名称与缩略图, 缩略图必须由该图形的路径本身生成, 与实际画出的轨迹一致
- **FR-011**: 用户必须能在图形库中调整分量数, 并即时看到图形随分量数变化

**手绘**

- **FR-012**: 用户必须能在画布上用指针(鼠标、触摸、触控笔)一笔画出路径, 绘制过程中实时显示
- **FR-013**: 松手后系统必须自动闭合路径并转换; 路径过短(少于 20 个采样点或长度小于画布短边的 5%)时提示并不转换
- **FR-014**: 绘制模式必须可以随时进入与退出, 退出时恢复此前的图形与播放状态; 并提供"清除"
- **FR-014a**: 转换前系统必须把手绘路径按弧长均匀重采样, 并按用户选择的"平滑程度"去除抖动; 平滑程度由一个滑块控制, 默认为轻度, 最低档接近原样, 调整后即时重新转换. 平滑不得改变路径的拓扑(自相交仍然保留)
- **FR-014b**: 最近一次手绘的原始路径必须在本次会话内保留, 使用户在转换后仍可调节平滑程度与分量数; 退出绘制模式或再画一笔后替换

**导入**

- **FR-015**: 用户必须能通过文件选择器或拖放导入 SVG 文件; 系统取出其中最长的一条路径进行转换, 并在多条路径时告知
- **FR-016**: 系统必须支持 SVG 路径中的直线、二次与三次贝塞尔曲线、圆弧及闭合指令, 并把曲线按弧长均匀取样
- **FR-017**: 无法解析或不含路径的文件必须给出明确说明, 当前函数不变; 导入只在用户设备上完成, 文件不上传
- **FR-018**: 导入不得让界面冻结: 转换耗时超过 0.5 秒时必须显示进行中的状态

### 关键实体

- **图形路径**: 一条有序的平面点列, 首尾相接. 来源为图形库、手绘或导入; 转换前的中间表示, 不保存.
- **内置图形**: 名称、缩略图、生成其路径的规则(如雪花的分形阶数、五角星的内外半径比). 只读, 随应用内置.
- **傅立叶函数**(已有实体): 转换的结果, 与手工搭建的函数完全相同, 不新增字段; 因此不影响已保存函数的格式.
- **绘制会话**: 手绘过程中的临时状态: 正在画的点列、是否进行中、最近一次完成的原始路径、当前平滑程度. 不保存(刷新后消失).

## 成功标准 *(必填)*

### 可衡量的结果

- **SC-001**: 首次使用的用户不阅读说明, 在 30 秒内、不超过 3 次操作, 能让旋转向量画出一朵雪花
- **SC-002**: 对全部内置图形, 分量数为 200 时画出的轨迹与图形本身的偏差不超过图形尺寸的 1%; 分量数为 20 时用户仍能一眼认出是哪个图形
- **SC-003**: 手绘松手到轨迹开始描绘, 用户感知为即时(0.3 秒内); 一个 2000 点的手绘路径或一个 5000 点的 SVG 路径在 1 秒内完成转换
- **SC-004**: 90% 的试用用户手绘一个简单闭合图形后, 认为画出的轨迹"就是我画的那个"
- **SC-005**: 生成的函数保存后重新打开、导出图片与视频, 100% 与手工搭建的函数行为一致; 已保存函数的格式与旧版本 100% 兼容
- **SC-006**: 在 200 个分量下, 播放、拖动参数与保留轨迹(功能 002)在主流个人电脑上保持 60 帧/秒; 分量列表的滚动与编辑无可见卡顿

## 假设

- "图形描述"限定为三种具体形式: 从内置图形库选择、在画布上手绘、导入 SVG 矢量文件. 用自然语言描述生成图形**明确不在范围内**(用户已确认).
- "使用函数绘制线条"理解为: 由生成的傅立叶函数驱动现有的旋转向量, 在二维绘图模式下描出图形; 不是另起一套绘图工具.
- 图形转换只处理一条闭合路径; 多路径、镂空、填充、颜色等 SVG 特性不在范围内(多路径取最长的一条).
- 位图(PNG/JPG)导入与轮廓提取不在本期范围内.
- 分量数上限由 50 提高到 200(用户已确认为全局放宽). 这会改动功能 001 的一处限制常量及相关的性能预算; 已保存的函数格式不变, 旧函数照常打开.
- 生成的函数带负频率分量(旋转方向相反的向量), 这是画出任意闭合图形所必需的; 功能 001 已支持负频率.
- 本功能依赖功能 001(编辑器)与 002(应用图形时使用其"轨迹保留"显示选项让整幅图形留在画面上).
