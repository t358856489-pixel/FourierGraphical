# Quickstart: 傅立叶函数可视化编辑器

**日期**: 2026-09-21 | **计划**: [plan.md](./plan.md)

本文件说明如何在本地运行、测试, 以及如何手动验收每个用户故事. 命令在实施阶段创建项目脚手架后生效.

## 环境要求

- Node.js ≥ 22, pnpm ≥ 9
- 验收用浏览器: Chrome / Edge、Firefox、Safari 的当前版本. 视频导出需要 WebCodecs(Chrome/Edge 94+、Safari 16.4+、Firefox 130+ 桌面版).

## 常用命令

```bash
pnpm install
pnpm dev                 # 本地开发服务器
pnpm test                # 单元 + 组件 + 集成测试 (Vitest)
pnpm test:coverage       # 覆盖率门槛: 整体 ≥ 80%, src/core ≥ 95%
pnpm test:e2e            # Playwright: 用户故事流程 + 视觉回归 + axe 可访问性检查
pnpm lint && pnpm typecheck
pnpm build && pnpm preview   # 生产构建; 首屏 JS < 300KB gzip, CSS < 50KB
```

## 开发顺序 (严格 TDD)

`src/core/` 是无 DOM 的纯函数库, 先行完成并由 [contracts/core-api.md](./contracts/core-api.md) 的契约表逐条驱动测试:

1. `keyframes` → `tracks` → `function` → `evaluator` → `playback` → `history` → `presets`
2. `render/drawFrame` + 画布舞台(完成后故事 1 可演示)
3. 播放控制与时间轴(故事 2) → **MVP 到此为止**
4. 关键帧 UI(故事 3) → 预设(故事 4) → 仓储、图片与视频导出(故事 5)

## 手动验收清单

每一节对应规范中一个用户故事的"独立测试".

### 故事 1 — 图形化编辑 (P1)

1. 打开应用 → 看到示例函数和图形, 不是空白.
2. 点击"添加分量"三次, 分别拖动振幅、频率、相位滑块 → 图形在**拖动过程中**持续变化.
3. 在画布上拖拽某个向量的端点 → 列表中它的振幅与相位同步变化.
4. 在振幅数值框输入 `abc`, 再输入 `999` → 出现范围提示, 值回到上一个有效值, 图形不变.
5. 停用一个分量再启用 → 贡献消失后恢复. 删除全部分量 → 出现空状态提示.
6. `Ctrl/Cmd+Z` 连续撤销 → 一次拖拽只占一步.
7. 切换"波形模式 / 二维绘图模式" → 分量与当前时间不变, 轨迹按新模式重新生成.

### 故事 2 — 时间控制 (P2)

1. 空格播放 → 图形连续变化, 时间读数递增. 再按空格 → 定格; 继续播放从原处接续.
2. 播放中把速度从 1× 调到 5× 再到 0.1× → 只变快慢, 图形无跳变.
3. 拖动时间轴到任意位置; 在时间框输入 `120` → 立即显示该时刻的图形.
4. `←/→` 单步前进后退. `Home` 重置 → 时间归零, 轨迹清空.
5. 设置循环区间 2s–6s 并启用 → 到 6s 回到 2s. 尝试把终点设为 1s → 被拒绝并提示.
6. 播放中拖动任意滑块 → 动画不中断.
7. 把一个分量频率设为 `1.37`、另一个 `−2.5` → 图形不闭合, 旧轨迹逐渐淡出, 画面不被填满.

### 故事 3 — 关键帧 (P3)

1. 时间归零, 为分量 A 的振幅添加关键帧(值 0); 拖到 5s, 把振幅改为 1 → 5s 处**自动**出现第二个关键帧, 参数标识为"已动画".
2. 拖到 2.5s → 振幅显示 `0.5`. 播放 → 向量长度在 5 秒内连续增长.
3. 把过渡方式改为"缓入缓出"、"保持" → 变化曲线相应改变.
4. 为频率设置关键帧 0s: `1`、4s: `−1` → 播放经过时旋转逐渐减速、反向, **无位置跳变**.
5. **一致性检查 (FR-018f)**: 从 0 连续播放到 3s 后暂停并截图; 重置后直接拖到 3s 截图 → 两图一致.
6. 拖动关键帧标记到另一时刻; 用键盘聚焦标记后按方向键移动、`Delete` 删除. 删除最后一个关键帧 → 参数恢复为固定值.
7. 每步编辑后撤销/重做 → 关键帧正确恢复.

### 故事 4 — 预设 (P4)

1. 选择"方波", 把分量数从 1 逐步拖到 20 → 波形逐步逼近方波. 从选择预设到得到 20 个分量 ≤ 3 步、≤ 15 秒 (SC-004).
2. 手动改一个参数后再选"锯齿波" → 先弹出覆盖确认; 取消则内容不变.

### 故事 5 — 保存与导出 (P5)

1. 保存并命名 → 出现在"我的函数"列表. 刷新页面 → 恢复到刷新前正在编辑的内容.
2. 打开已保存的函数 → 分量、关键帧、循环区间与保存时一致. 重命名、删除可用.
3. 导出图片 → PNG 与当前画面一致.
4. 导出视频(默认区间 10 秒) → 显示进度, 在主流电脑上 ≤ 30 秒完成 (SC-005a); 成片内容与同一区间的画面动画一致, 无掉帧.
5. 导出中点击取消 → 不产生文件, 当前状态不受影响.
6. 浏览器隐私模式下保存 → 提示失败原因, 编辑功能照常.

### 横切检查

- **键盘**: 不用鼠标完成故事 1–3 的主流程 (FR-024).
- **减少动态效果**: 在系统设置中开启后重新打开 → 不自动播放 (FR-025).
- **响应式**: 320 / 768 / 1024 / 1440 宽度下无横向滚动、无内容截断 (FR-026).
- **性能**: 50 个分量、其中 10 个参数带关键帧, 播放时无可见卡顿; 拖动滑块到图形变化 < 100ms (SC-002/003).

## 已知限制

- 频率高于约 30 圈/秒时, 旋转向量本身会出现"车轮效应"式的视觉混叠(显示器刷新率所限); 轨迹与波形不受影响. 降低播放速度即可观察.
- 已保存的函数只存在于当前浏览器; 清除站点数据会丢失. 本期不提供导入/导出函数文件.
- 撤销历史不跨页面刷新保留.
