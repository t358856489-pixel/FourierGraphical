# 功能规范: 查看并复制函数的数学表达式

**功能分支**: `004-view-copy-expression`
**创建时间**: 2026-10-08
**状态**: 草稿
**输入**: 用户描述: "函数绘制或者编辑完成后的数学表达式可以查看，并复制"

## Clarifications

### Session 2026-10-08

- Q: 除可读纯文本外还需要哪些复制格式? → A: 纯文本 + LaTeX; 不含代码片段
- Q: 带关键帧(随时间变化)的参数如何呈现? → A: 显示当前时刻的瞬时值, 并标注"含动画参数, 按 t = 当前时刻取值"; 不写成分段函数

## 用户场景与测试 *(必填)*

编辑器里的函数目前只以"一列分量参数"和"画出来的图形"两种面貌存在. 用户调好了一个波形、或从一朵雪花反推出了一组分量之后,
往往想知道"这到底是个什么式子": 写进笔记、贴到数学软件里验证、发给别人、或放进论文和课件. 本功能把当前函数以标准数学记法展示出来,
并允许一键复制. 表达式始终反映编辑器中的当前函数: 改一个参数, 式子随之更新.

### 用户故事 1 - 查看当前函数的数学表达式 (优先级: P1)

用户在编辑器中打开"表达式"视图, 看到当前函数对应的数学式子. 在二维绘图模式下默认看到复数形式
`z(t) = Σ Aₖ·e^{i(2π fₖ t + φₖ)}` 展开后的各项; 在波形模式下默认看到 `y(t) = Σ Aₖ·sin(2π fₖ t + φₖ)`.
用户可以在"复数形式"、"参数方程 x(t)、y(t)"、"波形 y(t)" 三种写法之间切换. 每一项按分量列表的顺序排列, 用分量的颜色标出,
系数按编辑器里的数值显示(振幅、频率为圈/秒、相位为度). 停用的分量不出现在式子里, 但有一行说明"已排除 n 个停用分量".

**优先级原因**: "查看"是复制的前提, 也是用户描述里的第一个动词. 单独交付就已经解答了"我搭出来的到底是什么函数".

**独立测试**: 用预设生成 5 项方波, 打开表达式视图, 逐项核对振幅 `4/(π·m)`、频率 `m×0.2`、相位 0 与分量列表一致; 改一个分量的相位, 式子中对应项立即更新; 停用一个分量, 该项消失且出现排除说明.

**验收场景**:

1. **给定** 当前函数有若干启用分量, **当** 用户打开表达式视图, **那么** 看到一个用标准数学记法书写的表达式, 项数等于启用分量数, 每项的振幅、频率、相位与分量列表中的值一致
2. **给定** 用户处于二维绘图模式, **当** 打开表达式视图, **那么** 默认显示复数形式; 处于波形模式时默认显示波形 `y(t)`; 用户切换写法后, 本次会话内记住选择
3. **给定** 表达式视图已打开, **当** 用户修改任一分量参数、增删分量、撤销或重做, **那么** 表达式在用户感知为即时的时间内更新, 不需要关闭再打开
4. **给定** 函数中有停用分量, **当** 查看表达式, **那么** 停用分量不出现在式子里, 视图中说明被排除的数量
5. **给定** 函数有 200 个分量, **当** 打开表达式视图, **那么** 视图在 1 秒内显示完整, 可滚动查看全部项, 滚动流畅
6. **给定** 函数没有任何启用分量, **当** 打开表达式视图, **那么** 显示"当前没有启用的分量"而不是空式子或 `0`
7. **给定** 用户只用键盘, **当** 操作表达式视图, **那么** 可以打开、切换写法、复制并关闭; 屏幕阅读器能朗读表达式的文字形式

---

### 用户故事 2 - 一键复制表达式 (优先级: P1)

用户在表达式视图中点击"复制", 当前显示的写法被放进系统剪贴板, 可以直接粘贴到文档、聊天或数学软件中. 复制成功后有明确的提示;
如果浏览器拒绝访问剪贴板, 用户仍能全选文本手动复制.

**优先级原因**: 这是用户描述的第二个动词, 也是查看的主要用途: 把式子带出编辑器.

**独立测试**: 打开表达式视图, 点击"复制", 粘贴到任一文本框, 确认得到的文本与视图中显示的内容逐字一致, 并且是每个等式一行的可读纯文本; 在禁止剪贴板的环境下点击"复制", 确认出现可全选的文本框与提示.

**验收场景**:

1. **给定** 表达式视图打开, **当** 用户点击"复制", **那么** 剪贴板中得到与当前显示写法一致的文本, 界面提示"已复制"
2. **给定** 用户复制了纯文本形式, **当** 粘贴到任意文本编辑器, **那么** 得到用常见数学符号(π、·、°, 上标用 `^{}` 记法, 负号用普通减号)书写的可读文本, 不含界面上的颜色或排版标记
3. **给定** 浏览器拒绝或不支持访问剪贴板, **当** 用户点击"复制", **那么** 界面说明无法自动复制, 并把表达式放在一个已全选的文本框中供手动复制
4. **给定** 函数有 200 个分量, **当** 用户复制, **那么** 复制在 1 秒内完成, 内容完整(不截断)
5. **给定** 用户复制后修改了函数, **当** 再次复制, **那么** 得到的是修改后的表达式

---

### 用户故事 3 - 以多种格式复制 (优先级: P2)

除了可读的纯文本, 用户可以选择把表达式复制为 LaTeX, 粘贴到论文、Markdown 笔记(Typora、Obsidian 等)或任何支持 LaTeX 的编辑器中直接渲染. 两种格式表达的是同一个函数, 系数与项数完全相同. 可直接运行的代码片段不在范围内.

**优先级原因**: 纯文本能满足"看懂与分享"; LaTeX 服务于写作这一进阶用途, 可以在前两个故事之后单独交付.

**独立测试**: 选择 LaTeX 格式复制, 粘贴到任一支持 LaTeX 的编辑器中渲染, 确认与视图中显示的表达式一致、没有语法错误; 对三种写法各做一次.

**验收场景**:

1. **给定** 表达式视图打开, **当** 用户选择 LaTeX 格式并复制, **那么** 剪贴板中得到当前写法的完整 LaTeX 表达式, 与纯文本形式的系数逐项相同
2. **给定** 复制了 LaTeX, **当** 在支持 LaTeX 的工具中渲染, **那么** 显示为与视图中一致的数学式子, 没有语法错误; 200 项的表达式同样能渲染
3. **给定** 用户切换了格式, **当** 下次打开表达式视图, **那么** 本次会话内记住上次选择的格式
4. **给定** 剪贴板不可用, **当** 用户复制 LaTeX, **那么** 与纯文本一样退回到已全选的文本框

---

### 边界情况

- 分量的参数带关键帧(随时间变化)时: 表达式使用当前播放时刻的瞬时值, 并在视图中标注"含动画参数, 按 t = 当前时刻取值"(时刻按编辑器的显示精度写出); 含动画参数的项以可见方式标记. 拖动时间轴或播放时, 这些项随时刻更新, 其余项不变. 不写成分段函数(用户已确认).
- 振幅为 0 的分量: 仍然作为一项显示(`0×…`), 因为它在分量列表中存在; 不自动省略, 避免用户以为分量丢了.
- 负频率: 显示为负号, 如 `e^{i(2π·(−0.4)t + 30°)}`, 不改写为共轭形式.
- 相位超出 ±360°: 按编辑器中的数值原样显示, 不归一化.
- 数值精度: 系数按最多 4 位小数显示, 末尾的 0 省略; 像 `-0.0000` 这样的负零显示为 `0`. 图形生成的函数(功能 003)系数本身已量化到 4 位小数, 因此表达式与实际求值完全一致; 手工输入超过 4 位小数的值时, 表达式按显示精度四舍五入, 并在视图中注明"显示精度 4 位小数".
- 只有一个分量: 不显示求和符号或多余的加号, 直接写出该项.
- 加号与负号: 项之间用 `+` 连接; 项本身不会出现负振幅(振幅范围为非负), 因此无需处理 `+ −` 的合并.
- 用户在表达式视图打开期间播放动画: 不含关键帧的项不随 t 变化(它们描述的是函数本身); 含关键帧的项按上一条随时刻更新, 更新频率以用户能读清数字为准, 不必每帧刷新, 且不得影响画布的流畅度.
- 剪贴板写入需要页面处于前台且由用户手势触发: 复制只响应用户点击或按键, 不自动写入剪贴板.
- 复制的文本足够长(200 项约数万字符)时: 一次写入, 不分段; 提示中说明项数.

## 需求 *(必填)*

### 功能需求

- **FR-001**: 系统必须提供一个"表达式"视图, 以标准数学记法展示编辑器中当前函数的表达式, 可从编辑器主界面一步打开和关闭
- **FR-002**: 表达式必须忠实于编辑器的求值约定: 第 k 项为 `Aₖ · e^{i(2π fₖ t + φₖ)}`, 其中 Aₖ 为振幅, fₖ 为频率(圈/秒), φₖ 为相位(度); 参数方程为 `x(t) = Σ Aₖ cos(2π fₖ t + φₖ)`, `y(t) = Σ Aₖ sin(2π fₖ t + φₖ)`; 波形模式显示的是其中的 `y(t)`
- **FR-003**: 系统必须提供三种写法——复数形式、参数方程、波形——并允许用户切换; 默认写法由当前呈现模式决定(二维绘图 → 复数形式, 波形 → 波形), 用户的切换在本次会话内保留
- **FR-004**: 表达式的各项必须按分量列表的顺序排列, 并以对应分量的颜色标识, 便于与列表和画面中的向量对应
- **FR-005**: 停用的分量不出现在表达式中; 存在停用分量时视图必须说明被排除的数量
- **FR-006**: 没有启用分量时视图必须显示明确的空状态文字, 不显示空式子
- **FR-007**: 表达式必须随函数的任何变化(参数修改、增删、启用/停用、撤销/重做、应用预设或图形)即时更新; 更新不得影响画布的播放流畅度
- **FR-008**: 系数的显示精度为最多 4 位小数, 省略末尾的 0, 负零显示为 0; 当有参数因此被四舍五入时, 视图必须注明显示精度
- **FR-009**: 用户必须能够一键把当前显示写法的纯文本形式复制到系统剪贴板; 复制成功时有可见且可被辅助技术读到的提示
- **FR-010**: 纯文本形式必须使用常见数学符号(π、·、°)与 `^{}` 上标记法书写, 负号用普通减号, 粘贴到任何纯文本环境(包括计算器与代码)都可读, 并与视图中显示的内容逐字一致
- **FR-011**: 当剪贴板不可用或被拒绝时, 系统必须说明原因, 并提供一个已全选的文本框供用户手动复制; 不得静默失败
- **FR-012**: 系统必须支持 LaTeX 作为纯文本之外的可选复制格式; 两种格式表达的函数相同, 生成的 LaTeX 在常见渲染器中无语法错误; 用户的格式选择在本次会话内保留
- **FR-012a**: 当函数含带关键帧的参数时, 表达式必须使用当前播放时刻的瞬时值, 明确标注"含动画参数, 按 t = 当前时刻取值"并标记受影响的项; 复制的文本中也必须带有这一说明
- **FR-013**: 表达式视图必须完全可用键盘操作, 焦点顺序合理, 所有控件有可读名称; 表达式本身必须有一个供屏幕阅读器朗读的文字形式
- **FR-014**: 200 个分量的函数必须能在 1 秒内完整显示与复制, 并保持视图滚动流畅
- **FR-015**: 本功能不改变函数的数据格式与保存内容: 表达式是由当前函数派生的只读视图, 写法与格式的选择属于会话偏好, 不写入已保存的函数

### 关键实体

- **表达式**: 由当前傅立叶函数派生的只读文本, 分为若干项, 每项对应一个启用的分量(振幅、频率、相位、颜色、顺序). 不保存, 随函数变化重新派生.
- **写法**: 复数形式 / 参数方程 / 波形三者之一. 会话偏好.
- **复制格式**: 纯文本 / LaTeX 二者之一. 会话偏好.
- **傅立叶函数**(已有实体): 表达式的唯一来源; 本功能不新增字段.

## 成功标准 *(必填)*

### 可衡量的结果

- **SC-001**: 用户不阅读说明, 在 2 次操作内(打开视图、点击复制)把当前函数的表达式放进剪贴板
- **SC-002**: 对任意函数, 把复制的表达式在独立的数学工具中按 t 求值, 得到的点与编辑器在同一时刻画出的向量末端位置一致: 系数未被四舍五入时逐点一致; 被四舍五入时每项系数的误差不超过 0.00005, 且视图已注明显示精度
- **SC-003**: 修改分量参数后, 表达式在 0.1 秒内更新; 更新期间画布播放保持 60 帧/秒
- **SC-004**: 200 个分量的函数, 表达式视图在 1 秒内完整显示, 复制在 1 秒内完成且内容完整
- **SC-005**: 表达式视图通过自动化无障碍检查, 零违规; 仅用键盘可完成全部操作
- **SC-006**: 95% 的试用用户在不看说明的情况下, 能说出表达式中某一项对应分量列表中的哪一个分量

## 假设

- "函数绘制或者编辑完成后"理解为: 表达式随时可看, 不要求用户先点"完成"; 它始终反映编辑器中的当前函数, 包括手工搭建、预设生成和从图形(功能 003)得到的函数.
- 表达式采用编辑器已有的约定: 频率单位为圈/秒(因此写成 `2π f t`), 相位以度表示并带 `°` 符号, 与分量列表中的数值一一对应, 便于核对; 不换算为弧度或角频率.
- 表达式描述的是函数本身而不是某一时刻的值: 对不含关键帧的参数, 播放时间 t 的变化不会改变表达式. 含关键帧的参数按当前时刻的瞬时值呈现并加以标注(用户已确认), 分段函数形式不在范围内.
- 纯文本使用 π、·、° 与 `^{}` 上标记法, 负号用普通减号(便于粘贴进计算器与代码), 不依赖任何排版引擎即可阅读; 排版渲染只用于视图内的显示, 不影响复制的文本.
- 项的顺序与分量列表一致, 不按频率或振幅排序, 以保持与列表、画面的对应关系.
- 复制格式限定为纯文本与 LaTeX; 可运行的代码片段(Python/JavaScript 等)与 Desmos/GeoGebra 等工具专用格式**明确不在范围内**(用户已确认).
- 本功能不提供"从表达式反向编辑"(在式子里改数字), 也不提供导入表达式; 它是只读视图.
- 本功能依赖功能 001 的函数模型与分量颜色, 不依赖功能 002、003 的具体能力; 不新增外部依赖, 不联网.
