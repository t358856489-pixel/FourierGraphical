**功能分支**: `002-canvas-display-options`
**创建时间**: 2026-09-21
**状态**: 草稿
**输入**: 用户描述: "1、我想把网格和坐标轴分离控制显示  2、我想修改可以编辑背景色  3、我要能控制划过的轨迹是否淡化消失"

## Clarifications

### Session 2026-09-21

- Q: 关闭"轨迹淡化"后轨迹如何保留(完整保留 / 只在窗口内不淡化 / 可调保留时长)? → A: 可调的保留时长(5 秒到 10 分钟, 以及"全部"); 同时最新的一段轨迹亮度最高, 逐渐过渡到"正常亮度", 更早的保留轨迹以正常亮度持续显示而不消失
- Q: 显示选项随谁保存(应用级偏好 / 外观随作品 / 全部随作品)? → A: 全部是应用级偏好: 随应用记住, 不随单个函数保存; 打开"我的函数"中的任何作品都不改变它们, 已保存函数的数据格式不变

## 用户场景与测试 *(必填)*

本功能在已有的傅立叶函数可视化编辑器(功能 001)之上, 给用户更多对画面外观的控制. 三项改动彼此独立,
任何一项单独交付都有价值.

### 用户故事 1 - 让划过的轨迹保留下来, 不再淡化消失 (优先级: P1)

现在旋转向量末端画出的轨迹会逐渐变淡, 几秒之后完全消失. 用户在"二维绘图"模式下想看到完整的图案——
尤其是频率不成整数比、需要很长时间才画完的图形——却只能看到最近的一小段. 用户希望有一个开关:
关闭"淡化"后, 划过的轨迹保留在画面上, 图案越画越完整, 并且可以自己选择保留多久(几秒、几分钟或全部);
保留下来的轨迹以稳定的"正常亮度"显示, 只有最新画出的一小段更亮, 让人一眼看出笔尖现在在哪里;
重新打开淡化后恢复现在的余辉效果.

**优先级原因**: 这是三项里唯一改变"能看到什么内容"的一项, 直接决定用户能否看到自己设计的完整图案,
也最影响导出的图片和视频的成品效果. 另外两项只改变外观.

**独立测试**: 在二维绘图模式下关闭"轨迹淡化", 从 0 秒播放到 20 秒, 把保留时长选为"全部", 确认 0 秒附近画出的轨迹仍然完整可见、亮度稳定在正常亮度, 而笔尖附近最新的一段明显更亮;
重新打开淡化, 确认轨迹恢复为只显示最近一段并逐渐变淡.

**验收场景**:

1. **给定** 轨迹淡化为开启(默认), **当** 播放时, **那么** 轨迹的表现与现在完全一致: 只保留最近一段, 越旧越淡
2. **给定** 用户关闭了轨迹淡化且保留时长为"全部", **当** 在二维绘图模式下播放时, **那么** 从 0 秒起划过的全部轨迹保留在画面上不消失: 最新的一段最亮, 向旧的方向逐渐过渡到正常亮度, 更早的轨迹一律保持正常亮度
2a. **给定** 用户关闭了轨迹淡化, **当** 把保留时长从"全部"改为 30 秒时, **那么** 画面立即只保留最近 30 秒的轨迹, 30 秒之前的部分不再显示; 改回"全部"后, 从 0 秒起的轨迹立即完整重现
2b. **给定** 轨迹淡化为开启, **当** 用户查看保留时长控件时, **那么** 该控件不可用(或不显示), 因为此时轨迹长度由现有的余辉效果决定
3. **给定** 轨迹淡化已关闭且画面上已有很长的轨迹, **当** 用户点击重置时, **那么** 时间回到 0, 轨迹被清空, 重新开始描绘
4. **给定** 轨迹淡化已关闭, **当** 用户拖动时间轴到更早或更晚的某个时刻时, **那么** 画面显示的是"从 0 秒连续播放到该时刻"应有的完整轨迹, 与实际怎么到达这个时刻无关
5. **给定** 轨迹淡化已关闭, **当** 用户修改任意分量的参数时, **那么** 已保留的轨迹立即按新参数整体重画, 不残留旧参数画出的线
6. **给定** 轨迹淡化已关闭, **当** 在波形模式下播放时, **那么** 波形曲线在可见的时间窗口内采用同样的亮度规则(最新的一段最亮, 过渡到正常亮度后不再继续变淡), 波形仍随时间向一侧流动
7. **给定** 轨迹淡化已关闭, **当** 用户导出图片或视频时, **那么** 成片中的轨迹与画面上所见一致

### 用户故事 2 - 分别控制网格和坐标轴的显示 (优先级: P2)

现在"网格"开关同时控制网格线和两条坐标轴: 要么都显示, 要么都不显示. 用户想要更干净的画面,
比如只保留坐标轴作为参照、去掉密集的网格线; 或者反过来只要网格. 用户希望网格和坐标轴各有一个独立的开关.

**优先级原因**: 改动小、使用频率高, 对截图和导出成品的观感改善明显; 但不影响用户能看到的图形内容.

**独立测试**: 依次试四种组合(都开、只开网格、只开坐标轴、都关), 确认画面上每次只出现被打开的那一项.

**验收场景**:

1. **给定** 应用刚打开, **当** 用户查看显示开关时, **那么** "网格"和"坐标轴"是两个独立的开关, 默认都为开启
2. **给定** 两者都开启, **当** 用户关闭"网格"时, **那么** 网格线消失, 两条坐标轴仍然显示
3. **给定** 两者都开启, **当** 用户关闭"坐标轴"时, **那么** 坐标轴消失, 网格线仍然显示, 且原先坐标轴所在的位置显示为一条普通的网格线, 不出现缺口
4. **给定** 两者都关闭, **当** 用户查看画面时, **那么** 画面上只有图形本身(向量、圆、轨迹), 没有任何参照线
5. **给定** 波形模式, **当** 用户关闭"坐标轴"时, **那么** 波形区域的零值基准线也一并隐藏; 关闭"网格"时, 波形区域的时间刻度线也一并隐藏
6. **给定** 用户之前使用旧版本时关闭了"网格", **当** 升级后重新打开应用时, **那么** 网格和坐标轴都保持关闭(与升级前看到的画面一致), 不会因为拆分开关而突然多出坐标轴

---

### 用户故事 3 - 自定义画布背景色 (优先级: P3)

现在画布固定为深色的荧光屏背景. 用户想换成别的颜色——比如白色背景用于打印或放进浅色的课件,
或者某个特定的颜色来搭配自己的作品. 用户希望可以选择背景色, 并能一键恢复默认.

**优先级原因**: 对导出用于课件、打印的用户价值明确, 但需要额外处理"换了背景后线条还看不看得清"的问题,
范围比另外两项大; 且不选背景色并不妨碍使用其他任何功能.

**独立测试**: 把背景色改为白色, 确认网格、坐标轴、轨迹、向量全部仍然清晰可辨; 导出图片, 确认背景为白色;
点击"恢复默认", 确认回到原来的深色背景.

**验收场景**:

1. **给定** 默认的深色背景, **当** 用户选择一个新的背景色时, **那么** 画布背景立即变为该颜色, 无需确认或刷新
2. **给定** 用户选择了浅色背景(如白色), **当** 查看画面时, **那么** 网格、坐标轴、轨迹、向量、圆和画布上的提示文字自动改用深色系, 全部清晰可辨
3. **给定** 用户选择了深色背景, **当** 查看画面时, **那么** 上述线条与文字使用浅色系, 全部清晰可辨
4. **给定** 用户选择了与某个分量颜色非常接近的背景色, **当** 查看画面时, **那么** 该分量的向量和圆仍然可以辨认(例如通过描边或自动调整明暗), 不会完全融入背景
5. **给定** 用户已自定义背景色, **当** 点击"恢复默认"时, **那么** 背景回到应用默认的深色, 线条配色也随之恢复
6. **给定** 用户已自定义背景色, **当** 导出图片或视频时, **那么** 成片使用同样的背景色与线条配色
7. **给定** 用户已自定义背景色, **当** 关闭并重新打开应用时, **那么** 背景色保持为上次的选择

### 边界情况

- 轨迹淡化关闭且播放了很长时间(例如数小时)时: 画面与操作仍保持流畅; 保留的轨迹有一个时长上限, 超出上限的最早部分不再显示, 并向用户说明这一点, 而不是让应用变慢或卡死.
- 轨迹淡化关闭、频率不成整数比的图形长时间播放后轨迹铺满画面时: 这是用户主动选择的结果, 属于正常现象; 用户可以用重置清空, 或重新打开淡化.
- 轨迹淡化关闭时启用了循环区间: 每次回到循环起点时, 画面显示的是"从 0 秒连续播放到循环起点"应有的轨迹, 之后继续累积到循环终点; 不会因为循环次数增加而越叠越多.
- 保留时长短于"最新一段更亮"的过渡长度(例如 5 秒保留、2 秒过渡)时: 两者互不冲突, 过渡照常进行, 超出保留时长的部分不显示.
- 轨迹淡化关闭时"轨迹"显示开关被关掉: 不显示任何轨迹; 重新打开后立即显示到当前时刻为止应有的完整轨迹.
- 轨迹淡化关闭时导出视频, 且导出区间的起点不是 0: 成片第一帧就包含从 0 秒到该起点应有的完整轨迹, 与在画面上拖到该时刻所见一致.
- 用户输入的背景色不是合法的颜色值时: 提示格式要求并保留上一个有效的背景色.
- 用户选择了中等明度的背景色(深浅难分)时: 系统仍然确定地选用深色系或浅色系线条之一, 且所选配色下所有线条都满足可辨识的对比度要求.
- 用户开启了系统的高对比度或强制配色模式时: 画布外的界面遵循系统设置; 画布内仍使用用户选择的背景色, 线条保持可辨识.
- 旧版本保存的草稿里没有这些新选项时: 应用使用默认值(网格与坐标轴沿用旧的"网格"开关状态、默认背景色、轨迹淡化开启), 不报错、不丢失其他内容.

## 需求 *(必填)*

### 功能需求

**轨迹淡化**

- **FR-001**: 系统必须提供一个"轨迹淡化"开关, 默认开启; 开启时轨迹的表现必须与本功能之前完全一致
- **FR-002**: 轨迹淡化关闭时, 在二维绘图模式下, 系统必须显示保留时长范围内的全部轨迹, 范围内的轨迹不得消失
- **FR-002a**: 轨迹淡化关闭时, 用户必须能够选择轨迹的保留时长: 5 秒到 10 分钟之间可调, 另有"全部"一档(从 0 秒起, 受 FR-007 的上限约束); 默认为"全部". 改变保留时长必须即时生效
- **FR-002b**: 轨迹淡化关闭时的亮度规则: 最新画出的一段轨迹亮度最高, 在最近 2 秒的范围内向旧的方向平滑过渡到"正常亮度"; 早于这 2 秒的保留轨迹必须一律以正常亮度显示, 不再继续变淡. 正常亮度必须明显低于最高亮度、又足以清晰辨认(相对背景的对比度不低于 3:1)
- **FR-002c**: 轨迹淡化开启时, 保留时长控件必须不可用, 并让用户明白原因
- **FR-003**: 轨迹淡化关闭时, 在波形模式下, 系统必须对可见时间窗口内的波形采用 FR-002b 的亮度规则; 波形视图的时间窗口长度与滚动方式保持不变
- **FR-004**: 轨迹淡化关闭时, 任意时刻显示的轨迹必须只由"当前函数"与"当前时刻"决定: 拖动时间轴、连续播放、循环回绕、导出视频到达同一时刻时, 所显示的轨迹必须一致
- **FR-005**: 轨迹淡化关闭时, 修改任意分量参数后, 已保留的轨迹必须立即按新参数整体更新
- **FR-006**: 重置(时间回到 0)必须清空轨迹, 无论轨迹淡化是否开启
- **FR-007**: 保留时长的上限为 10 分钟, "全部"一档同样受此约束: 当前时刻超过 10 分钟时只显示最近 10 分钟的轨迹, 且界面必须向用户说明轨迹已达到保留上限
- **FR-008**: 轨迹淡化关闭且保留的轨迹达到上限时, 播放与编辑的流畅度必须满足成功标准 SC-004, 轨迹的形状不得出现肉眼可见的折线化或失真

**网格与坐标轴**

- **FR-009**: 系统必须把现有的"网格"显示开关拆分为"网格"与"坐标轴"两个独立的开关, 默认都开启
- **FR-010**: "坐标轴"开关必须控制本轮视图中的横、纵两条坐标轴以及波形视图中的零值基准线
- **FR-011**: "网格"开关必须控制本轮视图中的网格线以及波形视图中的时间刻度线
- **FR-012**: 坐标轴关闭而网格开启时, 坐标轴所在位置必须显示为一条普通网格线, 网格不得出现缺口
- **FR-013**: 两个开关必须与现有的"向量""圆""轨迹"开关在同一位置、以同样的方式呈现和操作, 并同样支持仅用键盘操作

**背景色**

- **FR-014**: 用户必须能够为画布选择任意不透明的背景色, 既可以从取色控件中选取, 也可以直接输入颜色值
- **FR-015**: 系统必须提供一组预置背景色供一键选用, 至少包含: 默认深色、纯黑、纯白、浅米色
- **FR-016**: 系统必须提供"恢复默认"操作, 使背景色与线条配色回到应用的默认外观
- **FR-017**: 背景色改变时, 画布必须即时更新, 无需确认
- **FR-018**: 系统必须根据背景色的明暗自动选择深色系或浅色系的线条配色(网格、坐标轴、轨迹、向量、圆、画布上的文字), 使每一种线条与背景的对比度都不低于 3:1, 文字与背景的对比度不低于 4.5:1
- **FR-019**: 每个分量的语义颜色必须在任何背景色下都能与背景区分: 当某个分量颜色与背景的对比度低于 3:1 时, 系统必须自动调整该颜色在画布上的明暗或为其加上描边, 同时保持它与分量列表中色标的对应关系可辨认
- **FR-020**: 系统必须校验直接输入的颜色值, 对非法输入给出明确提示并保留上一个有效的背景色
- **FR-021**: 背景色只影响画布区域; 画布以外的界面(面板、时间轴、对话框)外观不变

**一致性与持久化**

- **FR-022**: 本功能的全部显示选项(轨迹淡化、网格、坐标轴、背景色)必须同样作用于导出的图片和视频, 使成片与画面所见一致
- **FR-023**: 这些显示选项是应用级偏好: 系统必须在用户重新打开应用时恢复它们, 方式与现有的其他显示开关一致
- **FR-023a**: 打开、保存、另存、重命名或删除"我的函数"中的函数, 以及应用预设波形, 都不得改变任何显示选项; 已保存函数的内容与格式不因本功能而改变
- **FR-024**: 读取由旧版本保存的、不含这些新选项的数据时, 系统必须使用默认值并正常打开: 网格与坐标轴都取旧"网格"开关的状态, 背景色取默认, 轨迹淡化取开启
- **FR-025**: 切换这些显示选项不属于对函数的编辑: 不进入撤销/重做历史, 也不使当前函数变为"有未保存的修改"

### 关键实体

- **显示设置**(已有实体的扩展): 用户对画面呈现方式的偏好. 在现有的"向量 / 圆 / 轨迹 / 网格"开关之外, 新增: 是否显示坐标轴、是否淡化轨迹、轨迹保留时长(若干秒或"全部")、画布背景色. 属于会话级偏好, 随应用记住, 不属于某一个已保存的函数.
- **画布配色方案**: 由背景色派生、不单独保存. 包含网格、坐标轴、轨迹、向量、圆、文字各自的颜色, 以及每个分量颜色在当前背景下的实际显示色. 同一个背景色总是得到同一套配色.

## 成功标准 *(必填)*

### 可衡量的结果

- **SC-001**: 用户可以在 5 秒内、不超过 2 次操作, 完成"关闭轨迹淡化"、"改变轨迹保留时长"、"只隐藏网格保留坐标轴"、"把背景换成白色"中的任意一项
- **SC-002**: 轨迹淡化关闭、保留时长为"全部"时播放 60 秒: 0 秒附近画出的轨迹仍然可见, 其亮度与第 50 秒附近画出的轨迹完全相同(都是正常亮度), 且最新 2 秒内的轨迹亮度高于它们
- **SC-003**: 在预置的全部背景色以及任意用户自选的背景色下, 画布上的每一种线条与背景的对比度不低于 3:1, 文字不低于 4.5:1
- **SC-004**: 轨迹淡化关闭、保留的轨迹达到 10 分钟上限、50 个分量同时启用时, 动画在主流个人电脑上保持 60 帧/秒, 拖动任意参数后 100 毫秒内看到轨迹整体更新
- **SC-005**: 在任一显示选项组合下, 导出的图片与导出瞬间的画面逐像素一致; 导出的视频与同一时间区间内的画面动画一致
- **SC-006**: 使用旧版本保存过内容的用户升级后, 100% 能正常打开应用并看到与升级前一致的画面, 不出现报错或内容丢失
- **SC-007**: 本功能发布后, 默认设置下(不改动任何新选项)的画面与发布前逐像素一致

## 假设

- "最新的一段更亮"的过渡长度取 2 秒: 足以看清笔尖的位置与走向, 又不会让大部分图案处于过渡之中. 该长度本期不提供调节.
- 保留时长需要一个上限来保证流畅, 取 10 分钟: 远超绝大多数图案画完所需的时间, 又能避免长时间运行后变慢.
- 波形模式下波形视图本身就是一个随时间滚动的窗口, 旧的部分会移出画面; 因此该模式下关闭淡化只改变亮度规则, 不改变窗口长度; 保留时长设置只作用于二维绘图模式下的轨迹.
- 背景色为不透明纯色; 渐变、图片背景、透明背景(用于导出带透明通道的图片/视频)不在本期范围内.
- 用户只选择背景色; 网格、轨迹、向量等线条的颜色由系统自动搭配, 本期不提供逐项自定义线条颜色.
- 这些显示选项是应用级的偏好, 与现有的"向量 / 圆 / 轨迹 / 网格"开关同等对待: 随应用记住, 但不随某个函数一起保存到"我的函数"中. 因此打开另一个已保存的函数不会改变背景色. 让某个作品"记住自己的外观"不在本期范围内.
- 本功能依赖功能 001(傅立叶函数可视化编辑器)已完成, 并遵循其项目章程, 尤其是"图形只由当前函数与当前时刻决定"这一原则.
