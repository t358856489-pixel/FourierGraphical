# Quickstart: 从图形得到傅立叶函数

**日期**: 2026-09-24 | 环境与命令同功能 001; 无新依赖.

## 开发顺序
0. 上限 50 → 200: 改常量, 补边界测试, 轨迹预算改为按分量数自适应, 面板虚拟化, 基准加 200 分量场景 —— 先做, 因为三个故事都依赖.
1. `core/shape/spectrum`(性质测试先行)→ `builtins` → `documentStore.applyGenerated` + `useOverwriteGuard`.
2. 故事 1: 图形对话框"图形库"页签.
3. 故事 2: `core/shape/drawing` → 舞台绘制层.
4. 故事 3: `core/shape/svg`(防御性用例先行)→ "导入"页签.

## 手动验收
**故事 1**: 打开"图形"→ 选雪花(默认 150 分量)→ 画面切到二维绘图、从 0 播放, 5 秒后整朵六角雪花留在画面上; 把分量数拖到 10 → 变成圆润的近似; 撤销一步 → 回到之前的函数. 有未保存修改时先弹确认.
**故事 2**: 点"手绘"→ 画布上画一个心形松手 → 向量沿你画的轮廓描一遍; 拖平滑滑块到最低 → 抖动可见; 到最高 → 圆润; 画一个很短的点 → 提示"再画长一些"; 清除、退出 → 回到之前的播放状态.
**故事 3**: 导入一个含闭合路径的 SVG → 画出同样的图形; 导入含多条路径的 → 提示"已使用其中最长的一条"; 导入 PNG / 无路径的 SVG / 含 `<script>` 的 SVG → 明确提示, 函数不变, 无网络请求(开发者工具 Network 面板为空).
**横切**: 200 个分量下播放 60 fps, 面板滚动流畅; 生成的函数保存后重新打开一致; 默认画面回归快照不变.

## 已知限制
- 单条闭合路径; 多路径取最长; 不支持 SVG 的 `skew` 变换、镂空与填充.
- 上限 200 个分量; 更精细的图形会被平滑.
- 撤销恢复函数但不恢复显示选项(与功能 002 一致): 应用图形改动的"轨迹 / 淡化 / 保留时长"需手动改回.
