## 手动验收清单

### 故事 1 — 轨迹保留 (P1)

1. 不改任何设置播放 → 轨迹与以前一样: 只有最近一段, 越旧越淡.
2. 切到"二维绘图". 打开"画面"面板, 关闭"轨迹淡化"(保留时长默认"全部"). 重置后播放 20 秒 → 0 秒附近的轨迹仍在, 亮度稳定; 笔尖附近约 2 秒明显更亮, 并平滑过渡到正常亮度.
3. 让闭合图形反复描过同一条线 → 重叠处**不会**越描越亮.
4. 保留时长改为 30 秒 → 立即只剩最近 30 秒; 改回"全部" → 从 0 秒起的轨迹立即完整重现.
5. 重新打开"轨迹淡化" → 保留时长控件变为不可用并说明原因; 轨迹恢复余辉效果.
6. 关闭淡化, 把一个分量的频率改成 `1.37` → 整条保留的轨迹立即按新参数重画, 没有旧线残留.
7. **一致性**: 从 0 连续播放到约 15 秒后暂停并截图; 重置, 在"跳转到"输入同一时刻 → 两张图一致.
8. 设循环区间 4–8 秒播放几轮 → 轨迹不会越叠越多; 每次回到 4 秒时的画面相同.
9. 在"跳转到"输入 `900` → 控件旁出现"轨迹已达到 10 分钟保留上限"的说明; 画面流畅.
10. 波形模式下关闭淡化 → 波形在窗口内不再向旧的一端变淡到消失(最新一段更亮), 仍向一侧流动, 窗口长度不变.
11. 关掉"轨迹"显示开关 → 没有任何轨迹; 再打开 → 立即是完整轨迹.

### 故事 2 — 网格与坐标轴 (P2)

1. 工具栏上"网格"和"坐标轴"是两个开关, 默认都亮.
2. 只关"网格" → 网格线消失, 两条坐标轴还在; 波形区的时间刻度线消失, 零值基准线还在.
3. 只关"坐标轴" → 坐标轴消失; 原位置是一条普通网格线, 没有缺口; 波形区基准线消失.
4. 都关 → 画面上只有图形本身.
5. 用 Tab 聚焦两个开关, 空格切换 → 可用, 且不会触发播放/暂停.

### 故事 3 — 背景色 (P3)

1. "画面"面板里点"纯白" → 背景立即变白; 网格、坐标轴、轨迹、向量、圆全部变为深色系且清晰可辨.
2. 点"纯黑"、"浅米色" → 同样清晰. 用取色器选一个中灰、一个饱和的蓝 → 仍然清晰.
3. 把背景设成与"分量 1"色标几乎相同的颜色 → 分量 1 的向量和圆仍能辨认, 色相未变; 面板里的色标不变.
4. 十六进制框输入 `red`、`#12` → 提示格式为 `#RRGGBB`, 背景不变. 输入 `#FFF` → 变白, 框内显示 `#ffffff`.
5. "恢复默认" → 回到深色荧光屏背景与原配色.
6. 白色背景下导出图片 → PNG 背景为白色, 线条配色与画面一致; 导出一段视频 → 同样.
7. 面板、时间轴、对话框的外观不随背景色改变.

### 横切检查

- **记住设置**: 改动全部四类选项后刷新 → 全部恢复.
- **与作品无关**: 白色背景下保存函数甲; 改成黑色背景; 从"我的函数"打开函数甲 → 背景仍是黑色. 改显示选项不会出现"未保存"标记, 撤销也不影响它们. 应用预设 → 显示选项不变.
- **旧数据**: 用功能 001 的版本关掉"网格"后升级 → 打开时网格和坐标轴都是关闭的, 其他内容完好.
- **默认不变**: 不改任何新选项时, 画面与升级前一致.
- **性能**: `pnpm test:perf` 的三个新场景达标; 手动把 50 分量的函数放到 `t = 600`、"全部", 拖动滑块时整条轨迹跟手更新.
- **可访问性**: 仅用键盘完成三个故事的主要操作; axe 检查展开"画面"面板后的页面无 serious / critical 违规.

## 已知限制

- "全部"最多保留最近 10 分钟的轨迹.
- 高频、频率不成整数比、且保留数分钟的组合下, 轨迹会以较稀的采样加平滑曲线显示, 并在控件旁提示"轨迹已简化显示"; 闭合(周期性)图形不受影响.
- 背景色只支持不透明纯色; 线条颜色由系统自动搭配, 不能逐项自定义.
- 显示选项跟着应用走, 不随单个作品保存.
- 新版本写出的草稿不能被旧版本读取(不支持降级).
