# 功能规范: 傅立叶函数可视化编辑器

**功能分支**: `001-fourier-visual-editor`
**创建时间**: 2026-09-20
**状态**: 草稿
**输入**: 用户描述: "我想通过图形界面方式编辑傅立叶函数，然后控制时间和如何参数，来生成动态随着时间变化的图形。"

## Clarifications

### Session 2026-09-20

- Q: 图形采用哪种呈现形式(本轮+波形 / 仅波形 / 二维本轮绘图)? → A: 同时支持"波形模式"(本轮 + 联动波形)与"二维绘图模式"(本轮末端在平面上描绘图案), 用户可随时切换
- Q: 产品以什么形态交付和运行? → A: 网页应用, 在浏览器中运行, 无需安装, 数据保存在浏览器本地
- Q: 频率的取值规则是什么(仅整数 / 默认整数可切换 / 任意实数)? → A: 任意实数频率, 不做整数约束; 没有统一的周期概念, 时间轴向前无限延伸, 循环区间由用户手动设定
- Q: 是否支持把作品带出当前浏览器(分享链接 / 文件导入导出)? → A: 通过"导出为视频"来分享作品; 不提供分享链接和函数文件的导入/导出
- 分析后修订(2026-09-21): FR-023a 的 60 秒上限明确为成片时长; 新增 FR-013a(默认自动播放)与 FR-004a(拖拽向量时暂停); FR-023d 明确为 MP4(H.264), 不提供 WebM 回退
- Q: 参数本身是否随时间自动变化(固定 / 简单自动变化 / 关键帧动画)? → A: 关键帧动画: 用户可在时间轴上为任意分量的振幅、频率、相位设置关键帧, 系统在关键帧之间自动过渡

## 用户场景与测试 *(必填)*

### 用户故事 1 - 图形化编辑傅立叶函数并实时看到图形 (优先级: P1)

用户打开应用后, 看到一个由若干"谐波分量"组成的傅立叶函数. 每个分量有振幅、频率、相位三个参数. 用户不需要书写任何公式, 而是通过滑块、数值框或直接在画面上拖拽来增加、删除、调整分量. 每一次调整, 画面上的图形都立即随之改变, 用户可以直观地理解每个分量对整体图形的贡献.

**优先级原因**: 这是产品的核心价值——"用图形界面而不是公式来编辑傅立叶函数". 没有它, 其余功能都无从谈起.

**独立测试**: 打开应用, 添加 3 个分量并分别调整其振幅、频率、相位, 确认图形随每次调整即时变化, 即可完整验证并交付"可视化编辑"的价值.

**验收场景**:

1. **给定** 应用刚打开, **当** 用户未做任何操作时, **那么** 画面显示一个预置的示例函数及其图形, 而不是空白画面
2. **给定** 已有一个函数, **当** 用户点击"添加分量"时, **那么** 分量列表新增一项带默认参数的分量, 图形同步更新
3. **给定** 已有若干分量, **当** 用户拖动某个分量的振幅、频率或相位控件时, **那么** 图形在拖动过程中持续更新, 无需确认或刷新
4. **给定** 已有若干分量, **当** 用户删除或暂时停用某个分量时, **那么** 该分量的贡献从图形中消失, 重新启用后恢复
5. **给定** 用户在数值框中输入了非法值(非数字或超出允许范围), **当** 输入结束时, **那么** 系统提示允许范围并保留上一个有效值, 图形不被破坏

---

### 用户故事 2 - 控制时间, 让图形动起来 (优先级: P2)

用户按下播放, 图形随时间连续演变: 各分量按自身频率旋转/振荡, 合成出的轨迹和波形被逐步描绘出来. 用户可以暂停、继续、重置、调整播放速度, 也可以拖动时间轴跳到任意时刻, 并逐步观察图形在某一时刻的状态.

**优先级原因**: "随时间变化的动态图形"是用户明确提出的第二个核心诉求, 但它依赖故事 1 中已经存在的函数和图形.

**独立测试**: 使用预置示例函数, 依次执行播放、暂停、调速、拖动时间轴、重置, 确认图形在每种操作下的表现符合预期.

**验收场景**:

1. **给定** 图形处于静止状态, **当** 用户点击播放时, **那么** 图形开始随时间连续变化, 并显示当前时间值
2. **给定** 动画正在播放, **当** 用户点击暂停时, **那么** 图形定格在当前时刻, 再次播放时从该时刻继续
3. **给定** 动画正在播放或暂停, **当** 用户调整播放速度时, **那么** 图形演变的快慢随之改变, 且不发生跳变
4. **给定** 任意状态, **当** 用户拖动时间轴到某一时刻时, **那么** 图形立即显示该时刻的状态
5. **给定** 任意状态, **当** 用户点击重置时, **那么** 时间回到零, 已描绘的轨迹被清除
6. **给定** 动画正在播放, **当** 用户修改任意分量参数时, **那么** 动画不中断, 图形从当前时刻起按新参数继续演变

---

### 用户故事 3 - 用关键帧让参数随时间变化 (优先级: P3)

用户希望图形不只是"转起来", 还能随时间变形: 比如某个分量的振幅在 5 秒内从 0 渐变到 1, 让图案逐渐"生长"出来. 用户把时间轴拖到某一时刻, 为某个参数打下一个关键帧; 再拖到另一时刻, 改变该参数的值, 打下第二个关键帧. 播放时, 系统在关键帧之间自动平滑过渡, 图形随之连续变形.

**优先级原因**: 这是用户明确要求的"控制时间和参数生成随时间变化的图形"的完整形态, 但它建立在故事 1(编辑分量)和故事 2(时间轴)之上, 且没有它前两个故事仍可独立交付价值.

**独立测试**: 为一个分量的振幅在第 0 秒和第 5 秒分别设置关键帧(值为 0 和 1), 播放并确认该分量的向量长度在 5 秒内连续增长, 拖动时间轴到第 2.5 秒时振幅显示为 0.5.

**验收场景**:

1. **给定** 某参数没有关键帧, **当** 用户在当前时刻为它添加关键帧时, **那么** 时间轴上该时刻出现关键帧标记, 该参数被标识为"已动画"
2. **给定** 某参数有两个及以上关键帧, **当** 播放或拖动时间轴经过它们之间时, **那么** 该参数的值按所选过渡方式连续变化, 参数控件同步显示当前值, 图形随之连续变形
3. **给定** 某参数已动画, **当** 用户在一个没有关键帧的时刻手动修改该参数时, **那么** 系统在该时刻自动新增一个关键帧记录新值, 而不改变其他关键帧
4. **给定** 时间轴上有关键帧, **当** 用户拖动某个关键帧标记到另一时刻、修改其值、或删除它时, **那么** 动画相应更新; 删除某参数的最后一个关键帧后, 该参数恢复为固定值
5. **给定** 某分量的频率带有关键帧, **当** 播放经过频率变化的区间时, **那么** 该向量的旋转保持连续, 只改变快慢与方向, 不出现位置跳变
6. **给定** 当前时刻早于某参数的第一个关键帧或晚于最后一个关键帧, **当** 图形被呈现时, **那么** 该参数分别取第一个或最后一个关键帧的值

---

### 用户故事 4 - 从预置波形快速开始 (优先级: P4)

用户不想从零搭建, 而是从方波、锯齿波、三角波等经典波形的预设出发, 选择分量个数后一键生成对应的傅立叶级数, 再在此基础上自由修改.

**优先级原因**: 显著降低上手门槛, 也最能体现"傅立叶级数逼近"的教学价值, 但不是核心编辑能力的前提.

**独立测试**: 选择"方波"预设并将分量数从 1 逐步调到 20, 确认图形逐步逼近方波.

**验收场景**:

1. **给定** 任意当前函数, **当** 用户选择一个预设波形时, **那么** 分量列表被替换为该波形的级数分量, 图形随之更新
2. **给定** 已选择预设, **当** 用户调整分量个数时, **那么** 分量列表与图形同步增减, 图形对目标波形的逼近程度相应变化
3. **给定** 当前函数已被用户修改过, **当** 用户选择预设将覆盖当前内容时, **那么** 系统先征得用户确认

---

### 用户故事 5 - 保存与导出作品 (优先级: P5)

用户把调好的函数保存下来, 以后可以重新打开继续编辑; 也可以把当前图形导出为静态图片, 或把一段时间内的动画导出为视频, 用于分享或教学材料.

**优先级原因**: 提升留存和可分享性, 但不影响核心的编辑与动画体验.

**独立测试**: 保存一个函数, 关闭并重新打开应用后加载它, 确认所有分量与时间设置一致; 导出图片并确认内容与画面一致; 导出一段 10 秒的视频并确认其内容与同一时间区间内的画面动画一致.

**验收场景**:

1. **给定** 用户编辑了一个函数, **当** 用户保存并命名时, **那么** 它出现在"我的函数"列表中
2. **给定** 列表中存在已保存的函数, **当** 用户打开其中一个时, **那么** 所有分量参数与时间设置被完整恢复
3. **给定** 画面上有图形, **当** 用户选择导出图片时, **那么** 得到一张与当前画面一致的图片文件
4. **给定** 画面上有图形, **当** 用户选择导出视频并指定起止时刻时, **那么** 系统显示导出进度, 完成后得到一个视频文件, 其内容与该时间区间内按当前呈现模式和显示设置播放的动画一致
5. **给定** 视频正在导出, **当** 用户点击取消时, **那么** 导出中止, 不产生文件, 当前函数与时间状态不受影响

---

### 边界情况

- 所有分量被删除或停用时: 画面显示空状态提示, 而不是报错或空白.
- 分量数量达到上限时: "添加分量"不可用并说明原因.
- 振幅为 0 或极大、频率为 0 或极高时: 图形保持可读(自动缩放或限幅), 动画不卡死.
- 多个分量频率不成整数比时(两种呈现模式均适用): 图形不闭合属于正常现象, 轨迹长度有上限, 超出部分逐渐淡出, 避免画面被填满.
- 两个关键帧被移动到同一参数的同一时刻时: 后移入者取代原有关键帧, 且该操作可撤销.
- 关键帧使振幅过渡为 0 或使频率过渡经过 0(旋转方向反转)时: 图形连续变化, 不报错、不闪烁.
- 删除或停用带有关键帧的分量时: 其关键帧随之移除或隐藏; 撤销删除后关键帧完整恢复.
- 应用预设波形时: 原有分量的关键帧随分量一起被替换, 包含在覆盖确认(FR-020)的提示中.
- 参数达到关键帧数量上限时: 添加入口不可用并说明原因.
- 循环区间的终点不晚于起点、或区间过短时: 系统拒绝该设置并提示原因, 保留上一个有效区间.
- 长时间持续播放(时间值很大)时: 图形精度与动画流畅度不得明显下降.
- 播放速度为 0 或极高时: 等同暂停, 或限制在允许的最大速度.
- 窗口尺寸变化或在小屏设备上使用时: 图形与控件重新布局, 不出现内容被截断.
- 浏览器本地存储不可用或空间已满时(如隐私模式): 编辑与动画功能照常可用, 保存时明确提示失败原因, 不丢失当前正在编辑的内容.
- 用户的浏览器不支持视频导出时: 视频导出入口不可用并说明原因, 图片导出与其他功能不受影响.
- 加载的已保存数据损坏或格式不兼容时: 提示用户并保持当前函数不变.
- 用户开启了系统的"减少动态效果"偏好时: 默认不自动播放, 由用户主动触发.

## 需求 *(必填)*

### 功能需求

**函数编辑**

- **FR-001**: 系统必须把傅立叶函数表示为若干谐波分量之和, 每个分量是一个旋转向量, 具有振幅、频率、相位三个可编辑参数; 频率可为任意实数(含小数与负数, 范围 -100 到 100, 单位为每单位时间的圈数), 符号表示旋转方向
- **FR-002**: 用户必须能够添加、删除、停用/启用、重新排序分量, 分量数量上限为 50
- **FR-003**: 用户必须能够通过连续控件(如滑块、拖拽)和精确数值输入两种方式编辑每个参数
- **FR-004**: 用户必须能够直接在图形上拖拽某个分量的可视化表示(如旋转向量的端点)来同时改变其振幅与相位
- **FR-004a**: 播放过程中在图形上按下并拖拽分量时, 系统必须暂停时间推进, 释放后恢复原播放状态
- **FR-005**: 系统必须校验所有参数输入, 对非法或越界输入给出明确提示并保留上一个有效值
- **FR-006**: 系统必须支持撤销与重做最近的编辑操作(至少 50 步)
- **FR-007**: 系统必须在首次打开时提供一个预置示例函数

**图形呈现**

- **FR-008**: 系统必须提供两种可随时切换的呈现模式, 两者共用同一组分量与同一时间状态:
  - **波形模式**: 旋转向量首尾相接的"本轮"视图, 与其末端纵向投影随时间展开的波形视图并排联动
  - **二维绘图模式**: 仅显示本轮视图, 由末端在平面上描绘出二维轨迹图案
- **FR-008a**: 切换呈现模式不得改变分量参数、当前时间与播放状态; 已描绘的轨迹按新模式重新生成
- **FR-009**: 系统必须在参数变化时即时更新所有视图, 无需用户确认
- **FR-010**: 系统必须允许用户高亮单个分量, 以区分它在图形中的贡献
- **FR-011**: 系统必须自动调整显示范围使图形完整可见, 并允许用户手动缩放和平移
- **FR-012**: 用户必须能够切换辅助元素的显示(旋转向量与圆、轨迹、坐标网格)

**时间控制**

- **FR-013**: 用户必须能够播放、暂停、重置动画
- **FR-013a**: 用户未开启"减少动态效果"偏好时, 应用打开后必须自动开始播放(开启时见 FR-025)
- **FR-014**: 用户必须能够在 0.1 倍到 10 倍范围内调整播放速度
- **FR-015**: 时间从 0 开始向前无限延伸; 用户必须能够通过时间轴拖动到已到达范围内的任意时刻, 直接输入一个时间值跳转, 并以固定步长前进/后退
- **FR-016**: 系统必须持续显示当前时间值
- **FR-017**: 系统不假设函数存在周期, 默认持续向前播放; 用户必须能够手动设定一个循环区间(起点与终点时刻), 启用后播放到终点即回到起点, 并可随时关闭循环
- **FR-018**: 播放过程中修改参数不得中断动画

**关键帧动画**

- **FR-018a**: 用户必须能够为任意分量的振幅、频率、相位分别添加、移动、修改、删除关键帧; 每个关键帧记录一个时刻和该参数在此刻的值; 每个参数最多 50 个关键帧
- **FR-018b**: 系统必须在相邻关键帧之间自动过渡参数值; 用户必须能够为每个关键帧选择过渡方式: 匀速、缓入缓出、保持不变直到下一关键帧(默认匀速)
- **FR-018c**: 没有关键帧的参数保持用户设定的固定值; 在第一个关键帧之前与最后一个关键帧之后, 参数分别保持首、末关键帧的值
- **FR-018d**: 系统必须在时间轴上显示关键帧标记, 并在参数控件上标识该参数是否已动画; 选中某个分量时, 时间轴突出显示属于它的关键帧
- **FR-018e**: 对已动画的参数, 用户在无关键帧的时刻手动修改其值时, 系统必须在该时刻自动新增关键帧; 在已有关键帧的时刻修改则更新该关键帧
- **FR-018f**: 频率随时间变化时, 向量的旋转角度必须保持连续, 不得出现跳变; 拖动时间轴到任意时刻所呈现的图形, 必须与从 0 连续播放到该时刻的结果一致
- **FR-018g**: 启用循环区间时, 每次回到区间起点, 所有参数与向量角度必须恢复为该起点时刻应有的状态
- **FR-018h**: 关键帧的增删改必须纳入撤销/重做(FR-006), 随函数一同保存(FR-021), 并体现在导出的视频中(FR-023a)

**预设、保存与导出**

- **FR-019**: 系统必须提供至少方波、锯齿波、三角波三种预设, 并允许用户指定分量个数(1–50)
- **FR-020**: 应用预设会覆盖未保存的修改时, 系统必须先征得用户确认
- **FR-021**: 用户必须能够命名保存函数, 并在之后列出、打开、重命名、删除
- **FR-022**: 系统必须在用户重新打开应用时恢复上次正在编辑的函数
- **FR-023**: 用户必须能够把当前图形导出为静态图片
- **FR-023a**: 用户必须能够把指定时间区间(起点与终点时刻, 默认取当前循环区间, 未设定时取从 0 开始、按当前播放速度恰好生成 10 秒成片的区间)内的动画导出为视频文件; 单个视频的**成片时长**(= 区间长度 ÷ 播放速度)上限为 60 秒
- **FR-023b**: 导出的视频必须反映导出时的呈现模式、播放速度与辅助元素显示设置, 且播放流畅度不受导出时设备性能影响
- **FR-023c**: 视频导出过程中必须显示进度并允许取消; 导出失败时必须说明原因且不影响当前编辑内容
- **FR-023d**: 导出的视频必须为 MP4(H.264)格式, 以便在主流播放器与社交平台直接播放; 浏览器无法编码该格式时, 视频导出入口不可用并说明原因

**可用性**

- **FR-024**: 所有编辑与时间控制必须可以只用键盘完成
- **FR-025**: 系统必须遵循用户设备的"减少动态效果"偏好, 此时不自动播放动画
- **FR-026**: 界面必须在手机、平板与桌面宽度下均可正常使用
- **FR-027**: 产品必须作为网页应用交付, 用户通过浏览器打开即可使用, 无需安装或注册; 必须在主流桌面与移动浏览器的当前版本上正常工作

### 关键实体

- **傅立叶函数**: 用户编辑的作品. 包含名称、一组有序的谐波分量(连同其关键帧)、上次使用的呈现模式、创建与修改时间.
- **谐波分量**: 函数的一个组成项. 属性: 振幅、频率(带符号, 表示旋转方向)、相位、是否启用、显示颜色. 振幅、频率、相位各自要么是固定值, 要么由一组关键帧决定. 属于一个傅立叶函数.
- **关键帧**: 某个分量的某个参数在某一时刻的取值. 属性: 所属分量与参数、时刻、值、到下一关键帧的过渡方式. 同一参数在同一时刻至多一个关键帧.
- **时间状态**: 动画当前的播放情况. 属性: 当前时间、播放/暂停、播放速度、是否循环、循环区间的起点与终点. 与当前编辑的函数关联.
- **视图设置**: 用户对图形呈现的偏好. 属性: 呈现模式(波形 / 二维绘图)、缩放与平移范围、各辅助元素的显示开关、高亮的分量.
- **预设波形**: 系统内置的经典波形定义, 根据指定的分量个数生成一组谐波分量.

## 成功标准 *(必填)*

### 可衡量的结果

- **SC-001**: 首次使用的用户在 2 分钟内、不阅读任何说明的情况下, 能够添加一个分量、调整其参数并播放动画
- **SC-002**: 用户调整任意参数后, 图形在用户感知上即时响应(100 毫秒内看到变化)
- **SC-003**: 在 50 个分量同时启用且其中 10 个参数带有关键帧动画的情况下, 动画在主流个人电脑上保持 60 帧/秒, 在近三年的手机上不低于 30 帧/秒, 无可见卡顿
- **SC-004**: 用户从选择预设到得到 20 个分量的方波逼近图形, 所需操作不超过 3 步、时间不超过 15 秒
- **SC-005**: 保存后重新打开的函数, 其全部分量参数、关键帧与时间设置 100% 与保存时一致
- **SC-005a**: 用户导出一段 10 秒的视频, 在主流个人电脑上等待时间不超过 30 秒, 且成片无掉帧或画面撕裂
- **SC-005b**: 已完成主流程的用户, 能在 1 分钟内让某个分量的振幅在 5 秒内从 0 渐变到 1 并播放看到效果
- **SC-006**: 90% 的试用用户能在首次尝试时独立完成"编辑函数 → 播放 → 暂停 → 拖动时间轴"这一主流程
- **SC-007**: 所有核心操作均可仅用键盘完成, 且界面文字与图形元素的对比度满足 WCAG 2.2 AA

## 假设

- 用户描述中的"如何参数"理解为"各种参数"(振幅、频率、相位、分量个数、播放速度等).
- 可设置关键帧的参数限于各分量的振幅、频率、相位; 分量的启用状态、颜色、播放速度与视图设置不支持关键帧.
- "傅立叶函数"理解为由有限个正弦谐波分量叠加而成的傅立叶级数; 不包含对任意信号做傅立叶变换/频谱分析.
- 预设波形(方波、锯齿波、三角波)生成的分量频率为基频的整数倍, 应用后用户可自由改为任意实数; 预设面向波形模式设计; 在二维绘图模式下应用预设同样有效, 但不另外提供二维图案预设.
- 目标用户为学生、教师及对数学可视化感兴趣的爱好者, 单人本地使用, 无需账户、登录或多人协作.
- 保存的函数仅存于用户当前浏览器的本地存储中, 不上传到服务器, 因此不涉及隐私与合规要求; 更换浏览器或设备、清除浏览器数据会导致已保存内容不可用, 不提供跨设备同步.
- 导出范围为静态图片与视频; 导出动图(GIF)、分享链接、函数文件的导入/导出、从手绘路径或音频反推傅立叶系数不在本期范围内.
- 导出的视频不含声音.
- 界面语言为简体中文.
