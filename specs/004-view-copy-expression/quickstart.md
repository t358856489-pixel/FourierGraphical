# Quickstart: 查看并复制函数的数学表达式

**日期**: 2026-10-09 | 环境与命令同功能 001; 无新运行时依赖. 唯一新增的开发依赖是 `katex`(只在测试里验证 LaTeX 语法).

## 开发顺序
1. `core/expression/build`(`formatCoefficient` 与 `buildExpression`, 性质测试先行: 与 `vectorChain` 的一致性)→ `plainText` → `latex`(KaTeX 验证).
2. `state/expressionStore` + 自动保存不受影响的测试.
3. 故事 1: `features/expression/ExpressionPanel`(折叠面板、写法单选、项着色、排除/动画/精度说明)+ 分量面板头部的"表达式"按钮.
4. 故事 2: `copyText` 边界层 + 复制按钮 + 提示 + 回退文本框.
5. 故事 3: 格式单选(纯文本 / LaTeX).
6. 横切: 端到端(三个故事 + 键盘 + a11y)、视觉测试追加展开状态、`pnpm size`、回归快照不变.

## 手动验收
**故事 1**: 预设"方波"5 项 → 点"表达式" → 看到 `z(t) = 1.2732·e^{i(2π·0.2·t + 0°)} + 0.4244·e^{i(2π·0.6·t + 0°)} + …` 共 5 项, 颜色与分量列表一致; 切到波形模式再打开 → 默认显示 `y(t) = … sin …`; 把第 2 项相位改为 90 → 式子里对应项变成 `+ 90°`; 停用第 3 项 → 该项消失, 出现"已排除 1 个停用分量"; 应用图形库的雪花 → 式子立刻变成约 126 项, 滚动流畅; 删掉全部分量 → "当前没有启用的分量".
**故事 2**: 点"复制" → 提示"已复制 5 项的表达式"; 粘贴到任何文本框, 与面板内容逐字一致. 在地址栏用 `http://` 的非安全地址(或浏览器设置里禁止剪贴板)打开 → 点"复制" → 出现说明与已全选的文本框, Ctrl/⌘+C 能复制.
**故事 3**: 选"LaTeX"再复制 → 粘贴到 Typora/Obsidian 的 `$$ … $$` 中渲染为多行对齐的式子; 三种写法各试一次.
**动画参数**: 给某分量的振幅加两个关键帧 → 面板顶部出现"含动画参数, 按 t = 5.00 取值", 该项有标记; 播放时该项的系数每约 0.25 s 更新一次, 其余项不动; 画布保持流畅.
**键盘**: Tab 到"表达式"→ Enter → 焦点进入面板标题 → 方向键切换写法 → Tab 到"复制"→ Enter → 听到/看到提示 → Esc → 面板收起, 焦点回到按钮.

## 已知限制
- 含关键帧的参数只显示当前时刻的瞬时值; 不输出分段函数.
- 复制格式只有纯文本与 LaTeX; 没有 Python/JavaScript 代码或 Desmos/GeoGebra 格式.
- 视图内的排版是结构化 HTML(上标、着色), 不是完整的数学排版; 需要排版效果请复制 LaTeX.
- 写法与格式的选择只在本次会话内保留, 刷新后回到默认.
